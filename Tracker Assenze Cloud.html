Sincronizzazione cloud (Firebase)

Opzionale. Sincronizza i dati tra i tuoi dispositivi. Se non la configuri, l'app funziona in locale con Backup/Ripristino.

Solo locale — cloud non configurato
Firebase Console → Impostazioni progetto → Le tue app → App web.
Utenti diversi = ID diversi.
Stessa su tutti i tuoi dispositivi.
Nota: il cloud funziona quando apri il file nel browser via http(s), non nell'anteprima sandbox.
Guida: come configurare Firebase (una volta sola)
  1. Vai su console.firebase.google.com e accedi con un account Google.
  2. Clicca Crea un progetto, dai un nome (es. "tracker-assenze") e completa (puoi disattivare Google Analytics).
  3. Nel menu a sinistra: Crea → Firestore Database → Crea database. Scegli modalità produzione e una regione (es. europe-west).
  4. Vai su Regole (Rules) di Firestore, incolla le regole del file REGOLE-FIRESTORE.txt (Opzione A) e premi Pubblica.
  5. Apri Impostazioni progetto (ingranaggio in alto) → scorri fino a Le tue app → clicca l'icona web </>.
  6. Registra l'app (dai un nome qualsiasi, senza hosting) → copia l'oggetto firebaseConfig che appare.
  7. Torna qui: incolla firebaseConfig nel campo sopra, scegli un ID spazio (es. il tuo nome) e una chiave segreta a piacere.
  8. Premi Connetti e sincronizza. Sugli altri dispositivi usa lo stesso ID spazio e stessa chiave.
Ricorda: apri la pagina via http(s) (server locale o hosting), non con doppio clic (file://) e non nell'anteprima.
